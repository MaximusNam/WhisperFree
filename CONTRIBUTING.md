# Как прислать правку

## Окружение

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -e ".[dev]"
```

`[dev]` тянет `pytest` и `pytest-mock` (см. `[project.optional-dependencies]` в
`pyproject.toml`; там же extra `build` с PyInstaller — он нужен только для
`build.bat`). Ключ провайдера: скопируйте `.env.example` в `.env` и впишите
`GROQ_API_KEY` (бесплатный, карта не нужна: https://console.groq.com/keys).
Проверить, что всё живо: `check.bat` — запишет три секунды с микрофона и
напечатает расшифровку.

## Тесты

```bash
.venv\Scripts\python -m pytest
```

Сейчас их 692, и все зелёные. Если после вашей правки их меньше или есть
красные — правка не готова.

**Правка без теста не принимается.** Программа работает через системные API
Windows — низкоуровневый хук клавиатуры, буфер обмена, SendInput, папка
автозагрузки, — и регрессии там молчаливые: ничего не падает, просто в один
день текст перестаёт вставляться в терминал или срезается первый слог фразы.
Заметить это можно только тестом, написанным заранее.

## Две ловушки, на которых уже обожглись

Обе закрыты тестами. Если такой тест покраснел — это именно этот случай.

**1. `.bat` и `.vbs` — только CRLF и только ASCII.**
cmd.exe рассчитывает на два байта в конце строки. С одиночным LF он не падает с
внятной ошибкой — он теряет по символу на каждой границе строк, и пользователь
видит `'cho' is not recognized` и обрубок пути вместо `python.exe`. Кириллица в
батнике тоже не годится: файл читается в кодовой странице консоли (на русской
системе cp866), а не в UTF-8, поэтому весь русский текст печатает Python.
Закреплено `.gitattributes` и `tests/test_launchers.py`.

**2. `DEFAULT_CONFIG_TOML` в `config.py` — только raw-строка (`r"""..."""`).**
В ключах словаря замен есть регулярки вида `re:\bдокер\w*`, и обратные слеши
там принадлежат регулярке, а не Python. В обычной строке `\b` превращается в
управляющий символ, tomlkit отказывается разобрать собственный шаблон
программы, и конфиг молча откатывается на умолчания. Проверяет
`tests/test_config.py::TestTemplateIsRaw`.

## Секреты

Ключ API живёт только в `.env` или в переменной окружения. В `config.toml` он
не попадает никогда — ни при создании файла из шаблона, ни при сохранении
настроек; закреплено тестами `test_key_comes_from_environment_not_the_file` и
`test_template_contains_no_key`. Не добавляйте ключ в конфиг «для удобства»:
конфиг люди пересылают друг другу и прикладывают к issue. `.env`,
`config.toml`, `history.jsonl` и `logs/` не коммитятся — перед отправкой
убедитесь, что в диффе нет вашего ключа и вашей истории диктовок.

## Стиль кода

Комментарии и докстринги — по-русски и объясняют «почему», а не «что». Что
делает строка, видно из кода; а вот почему преролл именно 250 мс, почему
автозапуск через файл, а не через реестр, и почему модификаторы никогда не
перехватываются — не видно. Такие объяснения и есть ценность.

Форматирование: строки до 100 символов, `from __future__ import annotations`
сразу после докстринга, аннотации типов обязательны.
